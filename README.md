# KARINĒ — Luxury Salon & Wellness

A premium, editorial salon experience built with React, React Three Fiber, Three.js, Drei, GSAP ScrollTrigger, Lenis and Framer Motion.

## What changed

- Real WebGL hero scene instead of a flat “3D-looking” card layout
- Scroll-reactive camera and sculpture
- Reduced hero copy and stronger typography hierarchy
- Editorial service photography and cinematic full-screen sections
- Responsive mobile treatment with reduced rendering pressure
- Functional booking drawer that prepares/copies a structured appointment request
- Reduced-motion fallback for accessibility

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Before production launch, connect the booking drawer to the salon's real scheduling provider or backend endpoint and replace any demo copy/business details with verified salon information.
